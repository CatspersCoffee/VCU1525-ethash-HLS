This documents how to build the kernel with SDx 
i.e. how to turn the .cpp files that are in the /src directory into .chdl and .v files for 
later synthesis.

cd /mnt/cbea4eb1-844a-4b4b-8fbb-52ed04cf6ffa/xilinx_projects2/43/HLS/
make HLS_passthru2

this will run the source. the output will be put in:
/vivado_hls_prj/chls_prj/solution1/syn/vhdl
/vivado_hls_prj/chls_prj/solution1/syn/verilog
